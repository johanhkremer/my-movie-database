# My Movie Database

Movie app built on [The Movie Database (TMDB)](https://www.themoviedb.org/) API.

## Features

- Now playing, popular and top rated movies
- Browse movies by genre
- Movie and person detail pages
- Popular people
- Movie search and pagination
- Theme switching, saved in localStorage

## Tech stack

React 18, TypeScript, Vite, TanStack Query, React Router, React Bootstrap, Axios, SCSS

## Getting started

Create a `.env` file in the project root:

```bash
VITE_API_BASEURL=https://api.themoviedb.org/3
VITE_ADRESS_TOKEN=<your TMDB API read access token>
```

Then run:

```bash
npm install
npm run dev
```
